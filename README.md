# Data Science Internship – Cognorise Infotech

Three advanced projects from the Data Science track:

| # | Project | Folder | Dataset |
|---|---|---|---|
| 4 | Credit Card Fraud Analytics | `01_credit_card_fraud` | [ULB credit card fraud](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) |
| 5 | Customer Churn & Retention Analytics | `02_customer_churn` | [Customer churn](https://www.kaggle.com/datasets/rashadrmammadov/customer-churn-dataset) |
| 6 | Retail Sales Forecasting | `03_retail_sales_forecasting` | [Walmart store sales](https://www.kaggle.com/competitions/walmart-recruiting-store-sales-forecasting) |

## Setup

```bash
pip install -r requirements.txt
jupyter lab
```

Download each dataset from Kaggle into the project's `data/` folder, then open the notebook and run all cells.
Each notebook saves figures and result tables to its `reports/` folder.
